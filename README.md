## 📌 Projetos em Destaque

Aqui estão os principais sistemas que desenvolvi, focados em arquitetura backend escalável, automação de processos e engenharia de IA:

###  Inteligência Artificial & NLP
* **[TimeAware-RAG-Auditor](https://github.com/dyoussef11/TimeAware-RAG-Auditor)**
  > Framework avançado de Retrieval-Augmented Generation (RAG) projetado para mitigar a obsolescência informacional em sistemas de suporte técnico. O motor utiliza algoritmos de decaimento temporal e auditoria híbrida de dados para garantir que as respostas geradas por LLMs locais permaneçam precisas, contextualizadas e atualizadas.
  > 🛠️ *Python, Ollama, Hugging Face, NLP, Vector Databases, RAG Frameworks.*

###  Sistemas Backend & APIs
* **[SIAPESQ API Backend](https://github.com/dyoussef11/siapesq-api-backend)**
  > API robusta voltada para sistemas de pesquisa e gerenciamento institucional. Desenvolvida com foco em arquitetura limpa, segurança, manipulação eficiente de dados e alta performance para suportar fluxos complexos de requisições de backend.
  > 🛠️ *Node.js, TypeScript, Express, PostgreSQL/MySQL, REST API.*

* **[Irriga Management API](https://github.com/dyoussef11/irriga-management-api)**
  > API para gerenciamento e automação de sistemas de irrigação. O projeto aplica conceitos de engenharia de software para otimização de rotas, modelagem relacional de banco de dados e controle inteligente de parâmetros de hardware/sensores em ambiente backend.
  > 🛠️ *Node.js, TypeScript, Express, Relational Databases, Software Architecture.*
